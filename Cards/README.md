# Cards

The library itself. Each card is one idea in one file.

- Each folder here is a wing: one major subject, such as `06-Calculus and analysis`. The numbers give the reading order.
- Inside a wing, each folder is a shelf: a group of cards on one topic, such as `02-Derivatives`.
- Inside a shelf, each file is a card, such as `01-the-derivative.md`.

Each wing also has a `README.md`. That is the wing's own page, and it lists the wing's shelves and cards in order. Most wings have a `figures/` folder with the drawings their cards show.

## Where to start

Open a wing folder above, or start from the [syllabus](../SYLLABUS.md), which lists all the wings in reading order. Each card links to the earlier cards it builds on.

Each card's Python check, Rust check and Lean proof are in [`checks/`](../checks).
